# Contributing to RAUNDO

All work remains in this **full-scope ordinary Telegram Bot**, no Mini App, lite/full split or web admin. Before edits read AGENTS.md, docs/PRODUCT.md, docs/PROFILES_VERIFICATION.md, docs/BOT_UX.md, docs/ADMIN_SUPPORT.md, docs/ROADMAP.md, docs/STATUS.md.

Prefer small reviewed branches and conventional commits; inspect actual code, never delete WIP. Introduce one working tested feature at a time, but preserve entire full release scope. Run `ruff check .`, `pytest -q`, `python -m compileall -q src` when toolchain available, report truthful commands. Maintain migration/rollback safety and server-side rights checks; never commit tokens or private data. Record decisions and STATUS updates with SHA.

Systemic acceptance: investor and startup full profiles undergo distinct admin reviews, investor-only sector feed by default, consented direct contact or bot relay, honest dual rankings, voluntary Stars Premium, support and admin in same bot.
