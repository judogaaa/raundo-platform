# RAUNDO — статус исходного кода

Этот файл сознательно не содержит оперативные адреса серверов, идентификаторы платёжных кабинетов, сведения о физическом лице, конфигурации доступа, состояние продакшен-инфраструктуры и сведения о действующих токенах.

## Реализованные направления в ветке разработки

- Telegram-бот, анкеты стартапов/инвесторов и модерация.
- Веб-панель RAUNDO Admin для работы с пользователями, заявками и поддержкой.
- Хранение в PostgreSQL, Redis, миграции и набор автоматических тестов.
- Модули расчёта прав подписки и интеграции платёжных провайдеров.

## Что не гарантируется содержимым GitHub

- Фактическая доступность сервиса и внешних интеграций.
- Платёжная/юридическая готовность любой конкретной инсталляции.
- Совпадение конфигурации окружения с примером `.env.example`.
- Результат CI, локальных тестов и security-аудита на текущую дату.

Для демонстрации используйте отдельное тестовое окружение. Публикация этого репозитория допустима **только после ревизии всей истории, юридических шаблонов, исходников, вложений и удалённых веток**.
